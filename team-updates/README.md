# Team Updates

Monthly, sanitized digests that turn private reflection into useful team learning.

Raw reflections stay in `memories/`, `contemplations/`, `ponderings/`, and `work-patterns/`. This folder is for the material that can be shared: generalized lessons, reusable patterns, tooling observations, and open questions that invite better discussion.

## Publishing Boundary

Use `Sanitized Patterns` as the default:

- Share practices, tradeoffs, and recommendations.
- Remove personal context that only belongs in reflection.
- Remove customer, teammate, and project-sensitive details.
- Keep source links so every claim can be traced back to repo evidence.

## Monthly Workflow

1. Finish the monthly retrospective.
2. Review weekly `Team insight candidate` fields.
3. Pick the strongest 3-6 signals.
4. Generalize them into a team-facing digest.
5. Promote durable lessons into `decisions/`, `work-patterns/`, or `ponderings/`.
