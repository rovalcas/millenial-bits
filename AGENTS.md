## 🔄 How to Use This Repo

**For Future Me:**
- Read README.md first for context
- Check REFLECTION_SYSTEM.md to understand the system
- Use work-patterns/ to understand your habits
- Review decisions/ before making similar choices
- Reference 	ools-and-setup/ for preferences

**For AI Assistants:**
- Use .github/copilot-instructions.md as the interaction guide
- Check memories/REFLECTIONS_INDEX.md for recent context
- Review related decisions/ and ponderings/ for background
- Leverage work-patterns/ to match your style

**Adding New Content:**
- **Weekly reflections**: Run \.\scripts\New-WeeklyReflection.ps1\ (every Friday)
- **Monthly retros**: Run \.\scripts\New-MonthlyRetrospective.ps1\ (month-end)
- **Quarterly reviews**: Run \.\scripts\New-QuarterlyReview.ps1\ (quarter-end)
- **Team updates**: Add sanitized monthly digest to \team-updates/\
- **Decisions**: Add to \decisions/\ with status & review date
- **Explorations**: Add to \ponderings/\ with status
- **Reflections**: Add to \contemplations/\ or \memories/\
