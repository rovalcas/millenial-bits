# Work Pattern: Repository Engagement Map

**Analysis Date**: May 2026
**Data Period**: Recent months

## Observations

You engage deeply with 1-2 primary projects at a time, then context-switch to new work. Sessions typically:
- Focus on single repository per session
- Cover related changes (feature + supporting doc updates)
- Include documentation in standard practice
- Favor reusable solutions over one-offs

## Typical Pattern

- **Deep focus periods**: 4-6 weeks on major initiative
- **Context switching**: Between unrelated projects
- **Documentation**: Always included in work
- **Reusability bias**: Building shared assets, not temporary fixes

## Energy Observations

- High energy: Infrastructure work, teaching/documentation, knowledge systems
- Lower energy: Quick feature shipping, firefighting, undefined scope
