# Templates for Regular Entries

Use these templates to maintain consistency when adding new reflections, retrospectives, and reviews.

---

## 📅 Weekly Reflection

**File**: `memories/YYYY-MM_Week_N_Reflection.md` (e.g., `2026-05_Week_2_Reflection.md`)
**Frequency**: Every Friday or Monday
**Purpose**: Lightweight weekly check-in on what moved the needle

```markdown

**Status**: Reflecting
**Projects Touched**: CLI_AiInstructions, copilot-cli-for-beginners

- [ ] Win 2
- [ ] Win 3

- **Blocker 1**: Description → Resolution/Status
```

## How to Use These

1. **Copy the template** into a new file with the date format specified
2. **Fill it honestly** — these are for you, not for anyone else
3. **Keep it lightweight** — 30 minutes for weekly, 90 minutes for monthly, 2-3 hours for quarterly
4. **Review quarterly** to see patterns emerging
5. **Reference in code/PRs** when making related decisions
