## What Was Hard

⚠️ **Cross-Platform Portability**
- Copilot Skills ≠ Claude Code capabilities
- Skill design constraints are real
- Some features just can't port

⚠️ **Governance Complexity**
- Audit scope kept expanding
- Security concerns justified the scope
- Had to iterate on threat model

⚠️ **Tool Instability**
- Some platforms still evolving
- Breaking changes required rework
- Can't always control platform roadmaps

## Lessons Learned

### Infrastructure Moves Slowly (On Purpose)
Don't expect immediate adoption. Good infrastructure compounds over months/years.

### Documentation is Implementation
Spending time on SKILL.md wasn't "extra work"—it was the main work. Clear specs save rework.

### Security First Pays Off
audit-ai-inf became high-value because I assumed threats early, not late.

### PowerShell is Underrated
For infrastructure + corporate environments, it's surprisingly solid.
